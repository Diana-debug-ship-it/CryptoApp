# CryptoApp (Java / Clean Architecture / REST API)

Архивный проект мобильного приложения для мониторинга актуальных курсов криптовалют в реальном времени. Проект демонстрирует продвинутые навыки проектирования ПО с использованием принципов **Clean Architecture**, разделением на независимые слои и строгой инкапсуляцией данных.

⚠️ **Текущий статус:** Проект успешно завершен и находится в архиве.
## 🏗️ Архитектура проекта
Приложение полностью переведено на принципы **Чистой Архитектуры**, код разделен на изолированные слои:
* **Presentation Layer (Слой представления):** Реализован на базе MVVM (`ViewModel`, `LiveData`, `RecyclerView`), отвечает только за отображение данных пользователю.
* **Domain Layer (Слой бизнес-логики):** Содержит бизнес-правила приложения и сценарии использования (Use Cases). Полностью независим от фреймворков и внешних библиотек.
* **Data Layer (Слой данных):** Отвечает за получение данных из внешнего REST API и локального хранилища. Здесь реализованы репозитории, сетевые запросы и работа с БД.

## 🛠️ Технологический стек и паттерны
* **Язык программирования:** Java
* **Паттерн DTO (Data Transfer Object):** Использование сетевых моделей для безопасного получения данных из API без раскрытия внутренней логики приложения.
* **Паттерн DAO (Data Access Object):** Изоляция работы с базой данных на уровне сущностей.
* **Data Mapping (Маппинг данных):** Реализованы кастомные мапперы для преобразования объектов между слоями (из `DTO` в модели `Domain`, из моделей `Domain` в `DAO`/сущности БД и обратно). Это гарантирует, что изменения в API не ломают бизнес-логику приложения.
